Purpose of the Repository
This repository was created to complete the ITE110 Git and GitHub tutorial. The purpose of the project is to learn how to use Git and GitHub for version control, collaboration, branching, commits, pull requests, reviews, and merging changes.

Steps Followed
Installed Git on a local computer.
Created a GitHub account.
Created a local Git repository.
Created a GitHub repository and linked it to the local repository.
Added a classmate as a collaborator.
Created a new branch for development.
Added new files to the repository.
Committed the changes with descriptive commit messages.
Pushed the branch to GitHub.
Created a Pull Request (PR).
Assigned a collaborator as a reviewer.
Received approval from the collaborator.
Merged the branch into the main branch.
